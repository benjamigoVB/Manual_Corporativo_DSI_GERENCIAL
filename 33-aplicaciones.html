3.3 Mantenimiento de Aplicaciones

Consola central para registrar, auditar y gestionar el catálogo de aplicaciones, servicios web y sistemas satélite integrados con la plataforma DSI GERENCIAL.

📍
Ruta de Acceso al Módulo

Desde la barra superior, despliega el menú Mantenimientos y haz clic en la opción Aplicaciones.

1. Especificación Técnica de la Grilla de Aplicaciones

Vista panorámica donde se listan los sistemas habilitados, su identificador único de plataforma, los enlaces de servicio y los estados de operación.

CAMPO / COLUMNA CONTROL ESTADO / VALOR PROPÓSITO OPERATIVO Y REGLA DE NEGOCIO
Nombre / Nombre Corto Texto Alfanumérico Cadena Descriptiva Denominación completa y acrónimo del aplicativo integrado (ej. ADMIN DEV, PCE beta, SIRCE).
Client Id Código Criptográfico GUID / Alfanumérico Identificador unívoco del cliente para la validación de tokens y conexiones autorizadas.
Direccion URL / Endpoint Protocolo HTTP/HTTPS Dominio base o ruta permitida donde se ejecutan los servicios autorizados de la aplicación.
Scopes Parámetro de Acceso openid|profile Alcance de privilegios concedidos para consumo de identidades de usuario.
PKCE Parámetro Booleano Sí / No Exigencia de validación criptográfica de código de autorización para aplicaciones web y móviles.
Estado Badge de Estado Activo / Anulado Indica si el aplicativo se encuentra habilitado para recibir solicitudes de acceso.
Acciones Botonera Contextual 5 Comandos por Fila Acceso directo a ficha técnica, edición de parámetros, anulación, opciones y roles.

2. Detalle de Botones, Modales y Acciones Operativas

Documentación técnica paso a paso de cada ventana modal, comando superior y acción contextual por fila.

Botón: + Nuevo (Alta de Aplicación)

Abre el formulario modal para registrar un nuevo aplicativo en el catálogo central, definiendo credenciales y enlaces permitidos.

CAMPO / CONTROL TIPO REQ DESCRIPCIÓN SENCILLA
Nombre / Nombre Corto › Texto Sí (*) Denominación formal y sigla breve de la aplicación.
URLs (App / Auth / Redirect) › URL Sí (*) Enlace base, ruta de acceso y URL de redirección post-login.
Client ID / Secret › Criptográfico Sí (*) Identificador unívoco y clave secreta de vinculación.
Scopes / Grants › Parámetros Sí (*) Permisos (openid|profile) y flujo de autorización.
Usa PKCE › Checkbox No Habilita el protocolo seguro de intercambio de código.
Cerrar / Guardar › Botones — Cancela la operación o confirma el registro del nuevo aplicativo.

Acción de Fila: Ficha Técnica (Documentación)

Abre el visor de documentación donde se auditan los parámetros generales, llaves públicas y detalles de conexión del servicio.

Acción de Fila: Modificar Parámetros (Lápiz Azul)

Habilita la edición de la dirección URL, nombre corto o directivas criptográficas del aplicativo seleccionado.

CAMPO / CONTROL TIPO REQ DESCRIPCIÓN SENCILLA
Nombre / Nombre Corto › Precargado Sí (*) Actualiza la denominación o acrónimo del sistema.
URLs (App / Auth / Redirect) › Precargado Sí (*) Modifica los endpoints y redirecciones autorizadas.
Client ID / Secret › Parámetros Sí (*) Credenciales de enlace autorizadas.
Scopes / PKCE › Configuración Sí / No Alcance de tokens y validación de seguridad.
Cerrar / Guardar › Botones — Descarta o confirma los cambios efectuados.

Anular aplicación (Diana Naranja)

Permite dar de baja a la aplicación mas no la elimina de la base de datos.

Acción de Fila: Opciones de aplicación (Lista Azul)

Nos manda a una pantalla donde están las diferentes opciones de la aplicación que se señaló.

Opciones relacionadas a las aplicaciones: Podremos ver una pantalla con todas las opciones que hay en una aplicación; en el sistema se observará que esta aplicación puede tener más de 50 opciones (o funcionalidades). Los botones principales cumplen la misma dinámica de trabajo que en pantallas anteriores.

Botón + Nuevo (Crear Opción)

Permite crear una nueva opción a la empresa señalada.

CAMPO / CONTROL TIPO REQ DESCRIPCIÓN SENCILLA
Nombre Opción / Mostrar › Texto Sí (*) Código interno y nombre visible en el menú.
Padre › Desplegable Sí (*) Menú superior del que depende (-- Sin padre --).
Código Externo › Texto No Identificador o ruta en sistemas externos.
¿Es multiempresa? › Toggle No Define si funciona en múltiples razones sociales.
Cerrar / Guardar › Botones — Cancela o registra la nueva opción.

Botón Editar Opción

Permite editar los campos de la "Opción de la aplicación", en este caso tenemos la opción de Anular empresa damos clic en el botón editar y podremos modificar en caso se requiera.

CAMPO / CONTROL TIPO REQ DESCRIPCIÓN SENCILLA
Nombre Opción / Mostrar › Precargado Sí (*) Permite corregir el nombre o título visible.
Padre / Código Ext. › Configuración Sí / No Reasigna el menú superior o enlace externo.
¿Es multiempresa? › Toggle No Habilita o restringe a una sola empresa.
Cerrar / Guardar › Botones — Descarta o actualiza la opción de menú.

Botón Anular Opción

Botón que permite dar de baja una opción, mas no la elimina del sistema.

Acción de Fila: Roles (Escudo Azul)

Abre una pantalla donde están todos los Roles relacionados a la aplicación, por ejemplo: Analista, Administrador, etc.

En la pantalla hay botones ya vistos anteriormente que cumplen las mismas funciones de gestión.

Botón + Nuevo (Crear Rol)

Permite agregar nuevos roles a las aplicaciones, por ejemplo: Administrador, analista, etc.

CAMPO / CONTROL TIPO REQ DESCRIPCIÓN SENCILLA
Descripcion / Mostrar › Texto Sí (*) Nombre y etiqueta oficial del nuevo perfil.
¿Es rol Interno? › Toggle No Uso exclusivo de personal de sistemas.
Cerrar / Guardar › Botones — Cancela o registra el nuevo rol.

Botón Editar Rol

Permite editar los campos del Rol señalado.

CAMPO / CONTROL TIPO REQ DESCRIPCIÓN SENCILLA
Descripcion / Mostrar › Precargado Sí (*) Permite cambiar el nombre del perfil activo.
¿Es rol Interno? › Toggle No Modifica si es rol técnico interno o general.
Cerrar / Guardar › Botones — Descarta o persiste la actualización del rol.

Botón Asignar Opciones

Abre una nueva pantalla donde podremos ver todas las Opciones que tiene un Rol, podemos agregarle o quitarle opciones dentro de esa pantalla.

Al seleccionar los permisos que se requieren hay botones de ayuda rápida como:

• Botón Guardar permisos:

Guarda los permisos que se agregaron o quitaron a los roles.

• Botón Seleccionar todo:

Selecciona de manera masiva todos los permisos que existen.

• Botón Deseleccionar todo:

Quita todas las selecciones de los permisos que estaban marcados.

• Botones de expandir todo y contraer todo:

Ayuda a poder visualizar todos los permisos que existen para esa aplicación y el botón contraer comprime todos los permisos para tener una vista limpia de la pantalla.

ℹ️
Nota de Gobierno: Los permisos otorgados a los roles impactan directamente en las pantallas y funciones que los usuarios asignados podrán ejecutar dentro de cada aplicativo del sistema.
