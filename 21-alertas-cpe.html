2.1 Mantenimiento de Responsables Alerta CPE

Módulo para la administración, enrolamiento y vinculación de los supervisores técnicos encargados de atender las alertas automáticas de emisión y contingencia de Comprobantes de Pago Electrónicos (CPE).

📍
Ruta de Acceso al Módulo

Clic directo en el menú Alerta de la barra superior.

Especificación Técnica de la Grilla de Responsables

Vista panorámica de la consola principal donde se supervisa el padrón completo de técnicos dados de alta, su estado de asignación y las opciones de contacto directo.

CAMPO / COLUMNA CONTROL ESTADO O VALOR PROPÓSITO OPERATIVO Y REGLA DE NEGOCIO
Empresa Razón Social Texto Alfanumérico Empresa cliente asociada. Si no cuenta con asignación, permanece en blanco.
Responsable / Celular Identificación Texto y Teléfono Nombres completos del supervisor y número móvil registrado para el envío de notificaciones.
Tipo Usuario / Nota Categoría Código y Glosa Rol interno del usuario y notas u observaciones técnicas de enrolamiento en el padrón.
Bienvenida Botón WhatsApp Icono Interactivo Habilita el despacho del mensaje predeterminado de bienvenida y credenciales hacia el número móvil.
Estado Badge de Estado Activo / Inactivo Define si el colaborador se encuentra facultado para la recepción activa de alertas.
Asignado Badge de Vinculación Asignado / Pendiente Audita si el supervisor ya está vinculado formalmente a una empresa cliente activa.
Acciones Botonera de Fila Modificar / Anular Comandos para editar datos del contacto o dar de baja el registro de la plataforma central.

Detalle de Botones, Modales y Acciones Operativas

Espacios reservados para documentar las ventanas emergentes, botones superiores y acciones contextuales por fila de la pantalla.

Botón: Nuevo Responsable (Alta de Personal)

Despliega el modal de enrolamiento para registrar nombres, apellidos, teléfono móvil y empresa asignada.

CAMPO DEL MODAL TIPO DE ENTRADA PROPÓSITO OPERATIVO
Nombres Texto libre Nombres completos del supervisor técnico responsable.
Apellido paterno / materno Texto libre Apellidos legales para el padrón formal de colaboradores.
Teléfono Numérico Prefijo y número celular habilitado para recibir contingencias CPE.
Empresa Búsqueda / Selector Razón social a la cual pertenece institucionalmente el contacto.
Correo / Contraseña Alfanumérico Credenciales de acceso iniciales para ingresar a la plataforma.
Botones de Acción Grabar / Cancelar Guarda el alta del supervisor en la base de datos o cancela la acción cerrando el modal.

Botón: Asignar (Vinculación de Recursos y Empresas)

Abre la pantalla de asignación de recursos para vincular masivamente supervisores con sus respectivas empresas clientes.

Panel Izquierdo (Usuarios / Supervisores): Lista de supervisores dados de alta con opción de selección individual o múltiple.
Panel Derecho (Empresas Clientes): Catálogo de razones sociales a vincular para el monitoreo de sus comprobantes.
Botón Confirmar: Aplica y guarda la vinculación entre los técnicos y clientes marcados.

Botón: Exportar (Reporte Excel)

Descarga consolidada en formato .xlsx del padrón de supervisores y su estado de asignación actual para auditorías y control administrativo.

Acción: Mensaje de Bienvenida (WhatsApp)

Disparador directo hacia la API de WhatsApp Web o aplicación móvil para enviar la credencial de acceso y bienvenida al responsable.

Plantilla de Texto: Mensaje cordial prediseñado con las instrucciones y credenciales de acceso.
Botón Confirmar (Verde): Ejecuta el enlace hacia el chat oficial de WhatsApp con el número registrado.

Acciones de Fila: Editar y Anular

Acción: Editar Registro (Lápiz): Abre el formulario para actualizar el número de celular, notas o corregir datos del supervisor.
Acción: Anular / Eliminar (Aspa Roja): Diálogo de confirmación para desvincular o dar de baja definitiva al contacto de la lista.
💡
Nota Operativa

El despacho de alertas CPE depende de la correcta validación del número en estado Activo. Todo cambio de contacto debe ser previamente auditado por el área técnica para no interrumpir el flujo de contingencias.
