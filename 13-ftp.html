1.3 Distribución de Servidores FTP por Fuente

Consola de auditoría de conectividad remota para supervisar las rutas y servidores FTP asignados al intercambio de información, respaldo de bases de datos y transmisión de comprobantes. Integra estados de control para notificar oportunamente la ausencia de servidores enlazados.

1. Comportamiento y Notificación de Estado Vacío (Empty State)

Esta vista supervisa las carpetas y rutas remotas configuradas para guardar respaldos y transmitir comprobantes electrónicos:

Propósito del Monitoreo FTP: Permite revisar qué carpetas o servidores remotos de transferencia se encuentran vinculados a cada fuente de datos o empresa cliente para transferencias periódicas de archivos.
Detección de Inactividad (Sin Conexiones): Si no existen carpetas o servidores registrados y activos en el entorno seleccionado, el sistema muestra el icono de 'carpeta con cruz' junto al mensaje informativo "No se encontraron registros de servidores FTP activos".
Impacto Operativo: Informa al responsable del sistema y soporte técnico sobre la falta de carpetas externas disponibles para copias de seguridad automáticas o envío de comprobantes fuera de la red local.

⚠️
Advertencia Operativa

La presencia del estado vacío en este módulo requiere coordinar con el área de soporte técnico o infraestructura la parametrización de las rutas FTP corporativas, garantizando que los respaldos periódicos y la custodia externa de datos se ejecuten sin interrupciones.
